# Attica Attendance backend

Laravel 9 API, admin panel and web frontend host. Begin with the complete repository [quick start](../README.md) and maintained [developer guide](../frontend/docs/DEVELOPER_GUIDE.md).

The root local setup script provisions an empty local MySQL database. Standard production deployment requires the private environment, database/media backups, original application encryption key and configured integrations; see the restore instructions in the guide. Serve this application's public/ directory, not the repository root.
